Modificare una pagina
---------------------

Modificare il :field:`Contenuto <html>` per adattare la pagina all'azienda.
Una pagina modificata mantiene la propria versione quando il modulo viene
aggiornato: se la sorgente cambia, un avviso chiede di **ripristinare la
sorgente** o di **mantenere la propria versione**.
